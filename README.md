# 订单核对小助手

一个由 AI 辅助开发的早期试用工具，用于体验订单核对与回款核对建议流程。这个公开仓库只提供试用介绍和问题反馈入口，不包含应用源码或业务数据。

## 在线试用

- [订单核对小助手](https://dingdan-check-starter.starryjam19.chatgpt.site/)
- [回款核对建议](https://dingdan-check-starter.starryjam19.chatgpt.site/fifo.html)

## 使用边界

- **仅使用合成数据试用。** 请勿输入或上传真实订单、客户资料、银行流水、账号、交易凭证或其他敏感信息。
- **不是正式财务、记账或结算系统。** 输出可能出错，需要人工复核，不能作为正式账务、付款、结算或审计依据。
- **回款页面只提供核对顺序和候选排序建议，不代表认款成功。** 不能据此认定款项归属或核销应收。
- 本工具由 AI 辅助开发；试用结果不构成财务或专业意见。

## 反馈问题或建议

欢迎在 [Issues 反馈区](https://github.com/wzmJIM-sketch/dingdan-check-feedback/issues) 提交问题、使用困惑或改进建议。提交或评论需要登录 GitHub；**反馈内容会公开展示**。

请先查看已有反馈，避免重复。新建 Issue 时，建议写清：

1. 使用的是哪个页面，以及想完成什么。
2. 复现步骤：点击了哪里、使用了什么合成示例。
3. 预期结果与实际结果。
4. 使用的浏览器或设备；如附截图，请确保截图中只有合成数据。

请不要在 Issue、评论或附件中发布真实账务、个人资料、账号密码、密钥或其他敏感内容。请用虚构数据复现问题。

这个仓库是公开介绍与反馈入口，不是源码开源仓库；试用反馈不代表服务承诺或问题已被解决。
